🕐 안 해도 괜찮아요. 새 버전 타이머는 멈춤을 스스로 감지하고 다시 켜집니다. 아래 점검은 멈춤 자체를 줄이기 위한 것이라, 어려우면 건너뛰어도 타이머는 계속 쓸 수 있어요.

하나만 한다면 1번을 추천해요. 위에서부터 효과가 큰 순서입니다.

1안 쓰는 원격제어 프로그램 지우기쉬움약 5분

왜? 예전 원격지원 프로그램이 남긴 "가상 화면 장치"가 시계 그림 그리기에 끼어들어 충돌을 일으켜요. 효과가 가장 클 것으로 보여요.

  • 시작 버튼 → 제어판 → 프로그램 제거 열기
  • 이름에 원격 / Remote / Support가 들어간 프로그램 찾기
  • 지금 안 쓰는 것이면 제거 → 컴퓨터 다시 켜기

어떤 걸 지워야 할지 헷갈리면 — 프로그램 목록 화면을 사진 찍어 장원표에게 보내주세요. 뭘 지울지 알려드릴게요.

프로그램 제거 화면
2그래픽 드라이버 업데이트보통약 10분

왜? 드라이버(= 화면 부품을 움직이는 프로그램)가 오래되면 화면이 잠깐 끊기는 일이 잦아져요.

  • 시작 버튼 → 설정 → Windows 업데이트 → 선택적 업데이트에서 드라이버 업데이트 확인 후 설치
  • 더 확실한 방법(한 단계 더): 인터넷에서 "인텔 드라이버 및 지원 도우미"를 설치하면 알아서 최신으로 맞춰줘요

3화면 기다림 시간 늘리기 — 파일 하나 더블클릭선택사항약 2분

왜? 지금은 화면이 2초만 늦어도 Windows가 그림 담당을 강제로 재시작해요(이때 시계가 멈춤). 기다림을 8초로 늘리면 멈춤이 줄어요.
