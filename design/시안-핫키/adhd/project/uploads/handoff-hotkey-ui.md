# Analog Timer — 핫키 설정 UI 미니 핸드오프

> 요청: **전역 단축키 설정·녹화 UI의 3개 상태를 다듬은 시안**
> 이전 핸드오프(`handoff-ui-simplification.md`)의 토큰·제약이 그대로 적용됩니다.
> 첨부 스크린샷 3장은 전부 **실제 구현 캡처**(목업 아님)입니다.

---

## 1. 컨텍스트

전역 단축키(다른 앱 사용 중에도 동작: 기본 `Ctrl+Shift+Alt+Space/N/L`)가
추가됐고, 설정에서 액션별로 키를 직접 녹화해 바꿀 수 있습니다.
기능은 확정 — **다듬고 싶은 것은 시각 표현**입니다.

## 2. 첨부 캡처와 현재 구현

| 파일 | 상태 |
|---|---|
| `hotkey-settings-taken.png` | 설정 목록. 정상 조합 2개 + **선점된 조합 1개(⚠ 상태)** — "Next segment"에 ⚠ 아이콘 + danger(#E05252) 테두리 뱃지 + 우측정렬 경고문 |
| `hotkey-record-dialog.png` | 녹화 다이얼로그 — 제목(액션명), 안내문, 조합 미리보기 박스, faint(#46443F) 주의 한 줄, Cancel/Save |
| `hotkey-settings-taken.png`의 정상 행 | 조합 뱃지: bg(#0E0E0F) + border(#2E2E32) + radius 6, 단일 텍스트 "Ctrl+Shift+Alt+Space" |

동작 규칙(디자인이 지켜야 할 사실):
- ⚠ 상태는 "다른 앱이 그 조합을 선점해 등록 실패"를 뜻함 — 행을 탭하면 녹화로 진입
- 녹화 중 수식키만 누르면 "Ctrl+Shift+Alt+…" 진행형 표시, 일반 키에서 확정
- 잘못된 조합(Ctrl/Alt/Win 없음, 중복)은 Save 비활성 + danger 문구가 미리보기 아래 추가됨
- 치트시트(? 키)에서는 같은 조합이 **키캡 분리형**(각 키가 개별 뱃지)으로 표시됨

## 3. 질문 (이것만 답해주면 됩니다)

1. **조합 뱃지 표기 통일**: 설정은 단일 뱃지("Ctrl+Shift+Alt+L"), 치트시트는
   키캡 분리형(`Ctrl` `Shift` `Alt` `L`). 어느 쪽으로 통일할지, 혹은 맥락별
   유지가 맞는지.
2. **⚠ 선점 상태**: 현재 ⚠ + 빨간 테두리 + 우측정렬 경고문 한 줄. 행 전체
   디자인으로 더 나은 패턴이 있는지 (경고문 위치·행 배경 처리 등).
3. **녹화 다이얼로그의 faint 주의 한 줄**: "이 조합을 쓰는 다른 앱에서는 해당
   키가 동작하지 않게 돼요" — 톤·위치가 적절한지, "기능 불안" 철학과 충돌
   없는 더 나은 표현이 있는지.
4. **"기본값 복원"** 텍스트버튼(목록 우하단) 위치·무게가 적절한지.

## 4. 제약 (기존과 동일)

- 토큰: bg #0E0E0F · surface #1A1A1C · border #2E2E32 · text #E8E6E0 ·
  muted #6B6968 · faint #46443F · accent #F0C040 · danger #E05252
- Flutter Material 구현 가능 수준, 15개 언어(문구 길이 가변)
- 기능·동작 규칙 변경 없이 시각 표현만
