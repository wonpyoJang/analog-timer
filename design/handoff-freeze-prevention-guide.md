# Analog Timer — 기기A "시계 멈춤" 예방 안내문 핸드오프

> 요청: **비개발자 실사용자에게 전달할 1장짜리 PC 점검 안내문 디자인**
> 앱 UI가 아니라 **사용자에게 보낼 문서/이미지**입니다. 형식은 자유
> (A4 1장 인쇄용, 카톡으로 보낼 세로 이미지, 또는 HTML 한 장 — 제안해 주세요).

---

## 1. 컨텍스트

실사용자(비개발자, Windows PC)가 "쓰다 보면 시계가 멈춰 있다"는 문제를
겪고 있습니다. 원인은 그래픽 드라이버 리셋(TDR) 후 앱 렌더가 회복되지
못하는 것으로 진단됐고, 앱 쪽에는 이미 자동 감지·재시작 방어가 들어갔습니다.

이번에 사용자 PC 환경 데이터를 확인해 보니 **freeze 확률을 낮출 수 있는
PC 쪽 점검 항목 3가지**가 나왔습니다. 이걸 사용자가 스스로(또는 주변의
도움을 받아) 따라 할 수 있는 안내문으로 만들어 새 버전 앱과 함께 전달하려
합니다.

**사용자 프로필 (중요)**: 비개발자. 레지스트리·드라이버라는 단어에 겁먹을
수 있음. "왜 하는지"를 한 줄로, "어떻게 하는지"를 클릭 단위로. 어려우면
건너뛰어도 앱은 동작한다는 안심 문구 필요.

## 2. 안내문에 담을 내용 (사실 관계 — 변경 금지)

우선순위 순서. 각 항목은 "왜 → 어떻게 → 안 되면 넘어가기" 구조를 권장.

### 항목 1 — 원격제어 프로그램의 "Mirage" 화면 드라이버 정리 (효과 최대 기대)
- 사용자 PC의 그래픽 장치에 `Mirage Driver`가 잡혀 있음. 이것은 원격제어
  프로그램(예: 알서포트/RemoteCall, 구형 원격지원 도구)이 설치하는 **가상
  화면 드라이버**로, 화면 합성에 끼어들어 그래픽 앱과 충돌하는 사례가 많음.
- 안내 내용: 지금 안 쓰는 원격제어/원격지원 프로그램이 있는지 확인
  ("제어판 → 프로그램 제거"에서 이름에 원격/Remote/Support가 들어간 것)
  → 안 쓰면 제거 → 재부팅.
- 판별이 어려우면: 개발자(장원표)에게 설치 프로그램 목록 사진을 보내달라는
  대안 경로 제시.

### 항목 2 — 인텔 그래픽 드라이버 업데이트
- 사용자 GPU는 Intel HD Graphics(구형). 드라이버가 오래되면 리셋(TDR)이
  잦음.
- 안내 내용: Windows 업데이트 → 선택적 업데이트에서 드라이버 확인, 또는
  "Intel 드라이버 및 지원 도우미(Intel DSA)" 설치 후 자동 업데이트.
  (Intel DSA 경로가 더 확실하지만 설치가 한 단계 늘어남 — 디자인에서
  난이도 표기로 구분해 주면 좋음)

### 항목 3 — 그래픽 응답 대기시간(TdrDelay) 늘리기 (선택, 난이도 높음)
- 그래픽 카드가 2초 안에 응답하지 못하면 Windows가 드라이버를 리셋함(이때
  앱이 멈춤). 이 대기시간을 8초로 늘리면 리셋 빈도가 줄어듦.
- 레지스트리 수정이라 비개발자에게는 **"원클릭 파일 실행" 방식**으로 제공
  예정: 개발자가 `.reg` 파일 2개(적용/되돌리기)를 ZIP에 동봉. 안내문에는
  "적용.reg 더블클릭 → 예 → 재부팅"과 "되돌리기.reg" 존재만 설명.
- 주의 문구 필수: 이 항목은 선택사항, 불안하면 건너뛰기.

### 공통 안심 문구
- "이 점검을 하지 않아도 타이머는 계속 쓸 수 있어요 — 앱이 멈춤을 감지하면
  스스로 다시 켜집니다. 이 안내는 멈춤 자체를 줄이기 위한 것입니다."
- 문제 지속 시 앱 안 "제작자에게 피드백" 버튼으로 연락 가능.

## 3. 질문 (이것만 답해주면 됩니다)

1. **매체**: A4 1장(인쇄) vs 카톡 전송용 세로 이미지 vs HTML 1장 — 비개발자
   1인에게 ZIP과 함께 전달하는 상황에서 무엇이 최선일지, 하나를 골라 그
   형태로 시안을 주세요.
2. **난이도 표기**: 항목별 난이도(쉬움/보통/어려움)와 소요시간을 어떻게
   보여줄지 — 사용자가 "여기까지만 해도 됨"을 스스로 판단할 수 있게.
3. **순서 vs 선택**: 3개 항목을 순서(1→2→3)로 제시할지, "하나만 한다면
   1번" 식의 선택형으로 제시할지.
4. **스크린샷 자리**: 각 단계에 Windows 화면 캡처를 넣을 자리(placeholder)를
   어떻게 잡을지 — 실제 캡처는 구현(개발자) 단계에서 채웁니다.

## 4. 제약

- 언어: 한국어 (단일 사용자용 — 다국어 불필요)
- 톤: 앱과 동일한 "불안 줄이기" 철학 — 경고·빨강 최소화, 차분한 안내
- 앱 디자인 토큰과 어울리면 좋지만(bg #0E0E0F · accent #F0C040 등),
  인쇄물이라면 밝은 배경 변형도 허용
- 기술 용어는 첫 등장 시 한 줄 풀어쓰기 (예: "드라이버 = 부품을 움직이는
  프로그램")
