# Analog Timer — UI 단순화 디자인 핸드오프

> 요청: **현재 룩앤필을 유지하면서, 처음 본 사용자가 "기능이 많아 불안"하지 않게 단순화된 UI 제안**
> 대상 화면: 메인 창(Windows 데스크톱) + 플로팅 위젯. 첨부 스크린샷 3장 참조.

---

## 1. 배경 — 무엇이 문제인가

실사용자 피드백: **"기능이 많아서 불안하다."**
기능 자체는 전부 존재 이유가 있어 **제거는 불가**합니다(§5 근거표). 문제는 기능이 아니라 **정보 구조**입니다 — 모든 기능이 첫 화면에 같은 시각적 무게로 동시에 노출됩니다. 원하는 것은 *기능 축소*가 아니라 **인지 부하 축소**: 핵심(시계·시작/정지)만 먼저 보이고, 나머지는 필요할 때 발견되는 구조.

## 2. 제품 개요

- **아날로그 시계 중심의 세그먼트 타이머**(뽀모도로류: 집중 25/휴식 5 등 반복) + **장기 스톱워치**(수백 시간 연속)를 하나의 시계 문자판에 동시 시각화
- 시계 문자판이 곧 제품 정체성: 타이머 = 안쪽 나선(주황), 스톱워치 = 바깥 링(초록)
- 항상 위에 떠 있는 **플로팅 위젯**(별도 미니 창)으로 작업 중 상시 확인
- Windows 데스크톱이 주력, 동일 코드로 모바일·웹 지원
- 주 사용자: 업무 루틴(집중/휴식 반복)을 하루 종일 돌리는 사람

## 4. 디자인 토큰 — **유지 대상** (룩앤필의 정의)

```
배경        bg        #0E0E0F   (다크 단일 테마)
표면(카드)   surface   #1A1A1C
테두리      border    #2E2E32
본문        text      #E8E6E0
보조        muted     #6B6968
포인트      accent    #F0C040   (노랑 — 브랜드/활성/복구 액션)
타이머      orange    #E07A52   (진한 변형 #C05A28)
스톱워치    green     #2EA84A
위험        danger    #E05252
세그먼트 팔레트: #E05252 #52B0E0 #52E08E #E07A52 #A052E0 #E0C052
```

- 폰트: **Pretendard** (400/500/…), 시계 숫자 일부 Bebas Neue
- 라운딩: 버튼/입력 8px, 카드 10px, 칩(pill) 20px
- 아이콘: 16px, muted 색 (활성/복구 계열만 accent)
- 버튼 패턴: `surface 배경 + border 1px + radius 8` 조용한 스타일
- 시계 문자판의 일러스트풍 그린/오렌지 톤은 제품 시그니처 — 변경 금지

## 6. 제약 조건

1. **기능 제거 금지** — 재배치·병합·숨김(2차 뎁스로 이동)은 전부 자유
2. **룩앤필 유지** — §4 토큰, 다크 테마, 아날로그 시계 중심 레이아웃
3. **Flutter Material**로 구현 가능한 수준 (커스텀 페인팅은 시계에 이미 사용 중)
4. 창 크기: 기본 460×860, 최소 420×680, 세로 스크롤 허용. 동일 레이아웃이 모바일·웹에도 쓰임
5. **15개 언어** — 문구 길이 가변(독일어 장문 등), 아이콘+툴팁 패턴 활용 가능 (전 버튼 호버 툴팁 이미 구현됨)
6. 복구 계열(재시작 등)은 완전히 숨기면 안 됨 — 단, **자동 멈춤 감지·자동 재시작이 이미 구현**되어 있어 수동 버튼의 노출 우선순위는 크게 낮출 수 있음 (트레이 메뉴에도 있음)
7. 접근성: 툴팁/시맨틱 유지, 대비 유지

## 7. 단순화 방향 힌트 (참고용 — 디자이너 재량으로 무시 가능)

- **헤더 7개 → 2~3개**: Widget 토글 + 설정(또는 ⋯ 오버플로)만 남기고, 재시작·위젯새로고침·오류리포트·동기화는 설정/오버플로 안으로. "문제 해결" 섹션으로 복구 계열을 묶는 안도 있음
- **컨트롤 2열 동시 노출 재고**: 타이머/스톱워치 중 실제 조작 중인 쪽 중심으로 (둘 다 상시 구동하는 사용자라 완전 탭 분리는 부적합할 수 있음)
- **세그먼트 편집기 progressive disclosure**: 기본 상태에선 "현재 루틴 이름 + 프리셋 칩"만, 리스트 편집(드래그·분·색·Loop)은 펼침/별도 시트
- **범례·진행바**: 시계에 통합하거나 첫 실행 후 자동 축소 후보
- **laps/log**: 탭 or 아코디언 통합
- 불안감의 본질은 "내가 모르는 버튼이 많다"이므로, **첫 화면 = 시계 + 시작/정지 + 위젯 토글** 수준까지 내려가는 안을 보고 싶음
