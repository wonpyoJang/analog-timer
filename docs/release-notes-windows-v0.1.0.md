# Analog Timer — Windows v0.1.0

아날로그 시계 페이스 위에 **세그먼트 타이머 + 스톱워치**를 동시에 시각화하는 데스크톱 타이머 앱.

## 📥 다운로드 & 설치

### 포터블 (권장 — 가장 간단)
`AnalogTimer-Windows-v0.1.0-portable.zip`

1. 압축 해제 → `AnalogTimer` 폴더 생성
2. 폴더 안 **`analog_timer.exe`** 실행
3. 파란 **"Windows의 PC 보호"(SmartScreen)** 창이 뜨면 → **추가 정보 → 실행**

설치 불필요 · 관리자 권한 불필요 · Windows 10/11 64bit.

### MSIX 인스톨러
`AnalogTimer-Windows-v0.1.0.msix` (게시자: zero, 자체 서명) — 다른 PC 설치 시
동봉된 `AnalogTimer-publisher.cer` 를 `LocalMachine\TrustedPeople` 에 등록 필요.

---

## ✨ 기능 (Windows)

- 아날로그 시계 위 타이머(안쪽 나선) + 스톱워치(바깥 링) 동시 시각화
- 세그먼트(할 것/휴식) 분 단위 편집, **순서 드래그 변경**, **색상 변경**, 루프
- **플로팅 위젯** — 다른 창 위에 항상 떠 있는 작은 시계 (드래그 이동, **모서리 드래그로 크기 조절**)
- 시스템 트레이 상태 표시 · 데스크톱 토스트 알림 · 상태 복원

## 🔧 v0.0.4 → v0.1.0 변경 사항

**기능 추가**
- 세그먼트 **순서 드래그 변경**(ReorderableListView)
- 세그먼트 **색상 변경**(팔레트 선택)
- 위젯 **크기 조절** — 우하단 모서리 드래그(종횡비 고정, 크기 저장/복원)
- 위젯 위치 기억/복원, 기본 우상단 배치
- 창/작업표시줄/exe/트레이 **아이콘 통일**(시계)

**동작 개선**
- "다음" 버튼 **2초 카운트다운 제거 → 즉시 실행** (본 앱·위젯 모두)
- 위젯 드래그 **떨림 제거**(네이티브 드래그)

**안정성 (버그 수정)**
- **앱이 안 켜지던 문제** 해결 — 좀비/숨김 인스턴스가 있어도 정상 기동
- **X 종료 시 크래시/좀비 프로세스** 해결 — 네이티브 즉시 종료로 깔끔히 닫힘
- **단일 인스턴스** — 중복 실행 시 기존 창을 앞으로(보이는 창 있을 때만)
- 위젯이 가끔 사라지던 현상 보강 — always-on-top 주기적 재확보 + 자동 재생성
- 위젯 회색 빈 화면 완화(불투명 배경)
