# Analog Timer — Windows v0.0.4

아날로그 시계 페이스 위에 **세그먼트 타이머 + 스톱워치**를 동시에 시각화하는 데스크톱 타이머 앱의 첫 **Windows 네이티브** 릴리스입니다.

> 시계판의 현재 분침 위치를 기준으로 타이머 잔여 시간을 쐐기로 그려, "몇 분 후에 끝나는지"를 시계에서 바로 읽을 수 있는 것이 차별점입니다.

---

## 📥 다운로드 & 설치

### 1) 포터블 (권장 — 가장 간단)
`AnalogTimer-Windows-v0.0.4-portable.zip`

1. 압축 해제 → `AnalogTimer` 폴더 생성
2. 폴더 안 **`analog_timer.exe`** 실행
3. 파란 **"Windows의 PC 보호"(SmartScreen)** 창이 뜨면 → **추가 정보 → 실행**
   - 서명 안 된 개인 앱이라 그렇습니다. 한 번만 누르면 됩니다.

설치 불필요 · 관리자 권한 불필요 · 폴더째 이동해도 그대로 실행됩니다.

### 2) MSIX 인스톨러 (정식 설치)
`AnalogTimer-Windows-v0.0.4.msix` (게시자: zero, 자체 서명)

- **본인 PC**: 이미 인증서를 신뢰 등록했다면 더블클릭 → 설치
- **다른 PC**: 동봉된 `analog-timer-publisher.cer` 를 관리자 권한으로
  `LocalMachine\TrustedPeople` 에 등록한 뒤 설치
  ```powershell
  # 관리자 PowerShell
  Import-Certificate -FilePath analog-timer-publisher.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
  ```

> 다른 사람에게 줄 때는 인증서가 필요 없는 **포터블 ZIP** 을 권장합니다.

## ✨ 기능 (Windows)

| 기능 | 설명 |
|------|------|
| 타이머 / 스톱워치 | 아날로그 시계 위 안쪽 나선(타이머) + 바깥 링(스톱워치) 동시 시각화 |
| 세그먼트 | 할 것/휴식 구간을 분 단위로 자유 편집, 루프 지원 |
| 플로팅 위젯 | 타이틀 **위젯** 버튼 → 다른 모든 창 위에 항상 떠 있는 작은 시계 창 |
| 시스템 트레이 | 트레이 아이콘에 현재 타이머 상태 툴팁 표시 |
| 데스크톱 알림 | 세그먼트 완료 / 전체 완료 시 Windows 토스트 알림 |
| 상태 복원 | 앱을 껐다 켜도 타이머/스톱워치 상태 복원 |

플로팅 위젯: 시계 영역을 **드래그**해 이동(위치 기억), 버튼으로 재생/일시정지 ·
**다음(2초 카운트다운, 다시 누르면 취소)** · 스톱워치 정지 · ✕(닫기).

## 🔧 이번 릴리스 변경 사항

- **Windows 네이티브 앱 신규 지원** (창 크기 고정·최소 크기, 트레이, 알림)
- **단일 인스턴스**: 두 번 실행해도 기존 창을 앞으로 가져오고 중복 실행 안 됨
- **닫기(X) = 완전 종료**: 트레이에 숨지 않고 깔끔히 종료 (상태 저장 후)
- **플로팅 위젯**
  - 다른 모든 창 위에 항상 표시(always-on-top)
  - 드래그 이동 시 **떨림 제거**(네이티브 드래그) + 위치 기억/복원
  - 기본 위치 작업영역 우상단
  - **다음** 버튼 2초 카운트다운/취소 (모바일·웹과 동일)
  - 배경 불투명화 — 일부 구형/Intel GPU 의 "회색 빈 화면" 완화
- **아이콘 통일**: 창/작업표시줄/exe/트레이 모두 앱 아이콘(시계)으로 교체
- MSIX 패키징(게시자: zero, 자체 서명)

## ⚠️ 알려진 제약

- **SmartScreen 경고**: 유료 코드서명 인증서가 없어 첫 실행 시 경고가 뜹니다(추가 정보 → 실행). 악성 아닙니다.
- **MSIX 사이드로드**: 자체 서명이라 다른 PC 설치 시 인증서 신뢰 등록이 필요합니다(위 참고). 무경고 배포는 유료 코드서명/Azure Trusted Signing 필요.
- **멀티기기 동기화**: 백엔드 엔드포인트(`/api/room`, Upstash) 가동 시에만 동작합니다(현재 데모 백엔드는 비활성일 수 있음).
